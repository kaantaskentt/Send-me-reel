Spellbreaker Arcade

Guide the wizard, launch the astral orb, and shatter every ward. This version is built with original HTML, CSS, and JavaScript only.

Move with arrow keys or drag on the playfield. Launch with Start or Space.

Controls

Arrow keys or drag the playfield to steer the wizard. Space launches, P pauses.

Goal

Clear all wards without letting the orb fall. The game resets when lives reach zero or the board is cleared.

Implementation note

The wizard, orb, wards, and glow effects are code-drawn. That is an intentional adaptation because no external assets are allowed.
